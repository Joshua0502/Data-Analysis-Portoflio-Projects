
# 🌍 COVID-19 Global Data Analysis Project

This project is a comprehensive SQL-based analysis of global COVID-19 data. It includes detailed insights into infection rates, death percentages, and vaccination progress across different countries and continents. The analysis results are visualized using Tableau for better clarity and storytelling. Visit my hosted Tableau Project [Here](https://public.tableau.com/views/CovidAnalysisDashboard_17502418062300/Dashboard1?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)

## 📊 Project Overview
* Infection and death trends over time
* Country and continent-wise death counts
* Percent of population infected or vaccinated
* Comparison between estimated and actual infection data
* Rolling vaccination totals per country

## 🔐 Key Requirements
*  Track the spread of COVID-19 across countries and continents to make informed decisions on containment and healthcare measures.
*  Understand infection and death trends over time to assess risk and allocate resources.
*  Identify regions with the highest infection and death rates for prioritizing vaccination or aid.
*  Compare actual vs. estimated infection growth for predictive planning and public policy response.
  
## 🧠 Skills Applied
* SQL querying & data aggregation
* Use of CTEs, views, temp tables
* Data cleaning & transformation
* Data visualization (Tableau)

## 📈 Tableau Dashboard
A Tableau dashboard was created to visualize key insights. It includes:
* Line Chart: Average population infected over time (with projections)
* Bar Chart: Death count by continent
* Map: Global infection density by country
* Summary Table: Total cases, total deaths, and calculated death percentage

## 📌 Key Insights
* United States showed the highest projected infection rates.
* Europe recorded the highest total death count among continents.
* Global death percentage remained around 2.11%.
* Infection density was visibly higher in North America and Europe.

## 💻 Tools & Technologies

## 📎 How to Use
* Clone this repo.
* Load the CovidDeaths and CovidVaccinations tables into your SQL Server.
* Run the provided SQL queries step by step.
* Open the Tableau file (if shared) or replicate using the SQL output.
